# 투운사 모의고사

투자자산운용사 시험 대비 퀴즈 사이트입니다. 휴대폰과 노트북 브라우저에서 바로 열립니다.

**사이트:** https://jeongtai.github.io/tuunsa-quiz/

## 기능

- 과목·영역을 골라 4지선다 문제를 풉니다.
- 답을 고르면 바로 O(정답) 또는 X(오답)가 크게 뜨고, 보기마다 맞고 틀린 이유를 설명하는 해설이 나옵니다.
- "보기별 해설" 칸에서 보기 4개마다 용어 정의, 이론(맞고 틀린 이유와 근거), 실무 포인트를 따로 볼 수 있습니다.
- 해설 아래 "실무에서는" 칸에 그 규칙이 실무에서 어떤 장면에 나오고 왜 그렇게 정해졌는지를 적어 두어, 외우기보다 이해하며 익힐 수 있습니다.
- "실무에서는" 칸 아래에 사례가 붙어 있습니다. **실제 사례**(DLF·라임·홍콩H지수 ELS·레고랜드·SVB·홈플러스 등 123건)는 연도와 출처 링크가 함께 나오고, 실제 사례가 없거나 확인되지 않은 문제는 **가상 사례**(A증권·B운용 등)로 표시됩니다.
- 실전 모의고사는 실제 출제 비율대로 100문항을 뽑고, 과목별 과락과 합격 여부를 채점합니다. 풀 때마다 다른 문제가 나오며, 아직 모의고사에 나오지 않은 문제부터 뽑아 문제은행을 한 바퀴 다 돌 때까지 같은 문제가 반복되지 않습니다.
- 계산 문제 33개(채권가격·듀레이션·VaR·선물 이론가격·풋콜패리티·샤프/트레이너/젠센·CAPM·배당할인모형·금융소득종합과세 등)가 각 영역에 섞여 있고, 해설에 "계산기 꿀팁" 칸으로 공식과 계산기 키 누르는 순서가 나옵니다. 해설에는 일반 계산기와 공학용 계산기(fx-570 계열) 키 순서가 모두 나옵니다.
- **공식 암기** 탭: 외워야 할 계산 공식 53개를 영역별로 모았습니다. '가리고 외우기'로 공식을 가리고 눌러서 확인할 수 있고, 공식마다 연결된 계산 문제를 바로 풀 수 있습니다.
- **계산기 사용법** 탭: 시험장 계산기 규정(공학용·재무용은 직접 리셋 후 감독관 확인), 일반·공학용·재무용 비교와 추천, 계산기 그림에 번호를 붙인 키 설명, 같은 문제를 두 계산기로 푸는 예시, 시험장 요령.
- 실전 모의고사에는 계산 문제가 영역별로 최소 문항 이상(합계 14문항 이상) 들어갑니다.
- 틀린 문제는 오답노트에 모여 다시 풀 수 있습니다.
- 풀던 문제와 기록은 기기 브라우저에 저장되어 새로고침해도 이어서 풀 수 있습니다.
- 키보드로도 풀 수 있습니다. 1~4로 답하고 Enter로 넘어갑니다.
- **업무모드**(상단 가방 버튼): 사이트 이름·탭 제목·아이콘이 "Weekly Brief" 문서처럼 바뀌고 색이 무채색으로 차분해집니다. 켜 두면 다음에도 유지됩니다.
- **화면 가리기**: `Esc`를 빠르게 두 번 누르거나 업무모드의 눈 버튼을 누르면 화면 전체가 "주간 시장 점검 메모"로 덮이고 탭 제목도 바뀝니다. 다시 `Esc` 두 번 또는 메모를 더블클릭(더블탭)하면 풀던 화면으로 돌아옵니다.

## 출제 범위

| 과목 | 영역 | 시험 문항 |
|---|---|---|
| 1과목 금융상품 및 세제 | 세제 및 절세전략, 금융상품, 부동산관련 상품 | 20 |
| 2과목 투자운용 및 전략Ⅱ·투자분석 | 대안투자, 해외증권투자, 투자분석기법, 리스크관리 | 30 |
| 3과목 직무윤리·법규·투자운용 및 전략Ⅰ·거시경제 | 직무윤리, 자본시장법·금융위 규정, 협회 규정, 주식·채권·파생상품 운용, 투자운용결과분석, 거시경제, 분산투자기법 | 50 |

합격 기준은 과목별 40% 이상, 전체 70% 이상입니다.

문제는 개인 정리노트 「금융 관련 내용 정리」를 바탕으로 만들었고, 2026년에 바뀐 내용을 반영했습니다. 반영한 주요 변경사항은 증권거래세 환원, 금융투자소득세 폐지, 고배당기업 배당소득 분리과세 신설, 가상자산 과세 일정, 비과세종합저축 요건 변경입니다.

## 구조

정적 사이트라 빌드가 필요 없습니다.

```
index.html   화면 뼈대
style.css    스타일, 다크모드 포함
app.js       퀴즈 로직
data/*.js    영역별 문제은행 (형식은 data/_SCHEMA.md)
data/calc.js 계산 문제 모음, 모의고사 계산 문항 할당
data/formulas.js 공식 암기 탭 내용
data/calcguide.js 계산기 사용법 탭 내용 (계산기 그림 키 배치는 app.js CALC_MODELS)
```

문제를 추가하려면 해당 영역의 `data/*.js`에 항목을 넣으면 됩니다. 로컬에서 볼 때는 `index.html`을 브라우저로 열면 됩니다.

```
config.js    사이트 이름(SITE_NAME·BRAND), 주소(SITE_URL), 광고(ADS), 문의(CONTACT) 등 설정
site.js      하단 고지·사례 기준일·정정 요청 문구 (앱과 tools 공용)
state.js     localStorage 값 검증 (타입·범위·알려진 문제 id, 어긋나면 버림)
ads.js       광고 슬롯. ADS.provider가 null이면 광고 코드를 그리지도 불러오지도 않음
tools/build-pages.js    문제별 정적 HTML과 sitemap 생성 (node tools/build-pages.js --out 폴더)
tools/sync-site.js      config.js를 고친 뒤 실행. index.html head, privacy·terms·404, manifest, robots, sitemap, ads.txt, og 이미지,
                        tools/hub/(허브 저장소용 초안)를 다시 만듦 (--check 검사만, --png og.png 다시 뽑기,
                        --url 주소 바꾸기, --cname tools/hub/CNAME 생성. 이 저장소 루트에는 CNAME을 만들지 않음)
tests/       node --test tests/*.test.js
```

도메인(geumsi.com)을 허브 저장소에 연결하고 이 저장소 이름을 tuunsa로 바꾼 뒤 아래 한 줄을 실행하고, tools/hub/ 파일을 허브 저장소 루트로 복사합니다. 순서와 주의점은 docs/HUB-SETUP.md에 있습니다.

```
node tools/sync-site.js --url https://geumsi.com/tuunsa/ --cname && node tools/build-pages.js
```

다른 사이트가 iframe으로 감싸면 본문과 광고를 그리지 않고 원 사이트 링크만 보여 줍니다(정적 페이지 포함). GitHub Pages는 응답 헤더를 정할 수 없어 JS와 CSP 메타로 처리합니다.

광고 자리는 문제 화면(답한 뒤에만, '다음 문제' 버튼 아래. 다음 문제로 넘어가면 지움), 결과 화면 맨 아래, 공식 암기·계산기 사용법 탭 맨 아래, 정적 문제 페이지 하단이며 config.js 슬롯으로 하나씩 켜고 끕니다. 업무모드와 화면 가리기 중에는 광고를 DOM에서 지우고(CSS로 숨기지 않음), 가리기를 풀어도 다시 넣지 않고 다음 화면 전환 때만 그립니다. 같은 광고 자리는 직전 요청 후 `ADS.minRefreshSec`(기본·최소 30초)이 지나야 다시 요청하고, 그 전의 해설 화면에는 광고를 넣지 않습니다. `index.html#q=문제id`로 열면 그 문제부터 같은 영역을 이어서 풉니다.
