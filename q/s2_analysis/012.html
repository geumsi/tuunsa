영업레버리지도(DOL)의 정의로 옳은 것은?

  1. 영업이익변화율 / 매출액변화율
  2. 주당순이익변화율 / 영업이익변화율
  3. 주당순이익변화율 / 매출액변화율
  4. 매출액변화율 / 영업이익변화율
정답과 해설 보기

정답 1번 영업이익변화율 / 매출액변화율

개념

레버리지도는 고정비 때문에 앞 단계의 변화율이 뒤 단계에서 몇 배로 커지는지 보는 지표다. 결과가 분자, 원인이 분모다 (매출 → 영업이익 → EPS).

DOL = 영업이익변화율 / 매출액변화율 = 공헌이익 / 영업이익
DFL = EPS변화율 / 영업이익변화율 = 영업이익 / (영업이익 − 이자비용)
DCL = EPS변화율 / 매출액변화율 = DOL × DFL
  • 공헌이익 = 매출액 − 변동비, 영업이익 = 공헌이익 − 영업고정비
  • 이자비용 = 재무고정비, EPS = 주당순이익
  • 예: 매출 1,000, 변동비 600, 영업고정비 200이면 공헌이익 400, 영업이익 200, DOL = 2다.

해설

DOL은 매출액(판매량)이 1% 변할 때 영업이익이 몇 % 변하는지를 나타내므로 영업이익변화율/매출액변화율이다.

암기

  • DOL(Degree of Operating Leverage, 영업레버리지도) = 영업이익변화율 / 매출액변화율
  • DFL(Degree of Financial Leverage, 재무레버리지도) = EPS(Earnings Per Share, 주당순이익)변화율 / 영업이익변화율
  • DCL(Degree of Combined Leverage, 결합레버리지도) = EPS변화율 / 매출액변화율
  • 결과가 분자, 원인이 분모: 매출 → 영업이익 → EPS

실무에서는

  • 반도체·항공처럼 고정비가 큰 산업은 DOL이 높아 업황 회복기에 이익이 급증하고 침체기에 급감한다.
  • 애널리스트가 실적 전망에서 이익 추정치를 크게 흔드는 이유가 여기에 있다.
  • DOL과 DFL은 분자·분모가 영업 단계인지 EPS 단계인지로 구분한다.

실제 사례 · 2023반도체 불황과 적자 전환

삼성전자 DS(반도체)부문은 2023년 1분기 매출 13조7300억원에 영업손실 4조5800억원을 냈다. 서버 고객사 재고 증가와 모바일·TV 수요 부진으로 매출이 줄자 공장 감가상각 같은 고정비는 그대로 남아 이익이 크게 무너졌다. → 고정비 비중이 큰 장치산업은 DOL이 높아 매출 변화보다 영업이익이 훨씬 크게 움직인다.

보기별 해설

1영업이익변화율 / 매출액변화율정답
용어

영업레버리지도(DOL)는 매출액 변화가 영업이익 변화로 확대되는 정도다.

이론

이 보기가 정답이다. 영업고정비가 있으면 DOL은 1보다 크고, 고정비가 클수록·매출액이 손익분기점에 가까울수록 커진다.

실무

업황 회복기에 매출이 조금만 늘어도 이익이 크게 느는 현상을 애널리스트는 '영업레버리지 효과'라고 부른다.

2주당순이익변화율 / 영업이익변화율
용어

재무레버리지도(DFL)는 영업이익이 1% 변할 때 EPS가 몇 % 변하는지를 나타낸다.

이론

이 보기는 틀렸다. 이 식은 DOL이 아니라 DFL이며, DFL은 이자비용이라는 재무고정비 때문에 생긴다.

실무

차입금이 많은 기업은 영업이익이 조금만 줄어도 순이익이 크게 줄어, 신용분석에서 금리 민감도를 볼 때 쓴다.

3주당순이익변화율 / 매출액변화율
용어

결합레버리지도(DCL)는 매출액이 1% 변할 때 EPS가 몇 % 변하는지를 나타내며 DOL × DFL과 같다.

이론

이 보기는 틀렸다. 이 식은 DCL이며, 영업고정비와 이자비용의 효과를 모두 담는다.

실무

매출 10% 변동에 DCL 3이면 EPS는 30% 움직이는 식으로 EPS 전망 변동 폭을 가늠한다.

4매출액변화율 / 영업이익변화율
용어

레버리지도는 '결과(이익) 변화율 / 원인(매출) 변화율' 꼴이다.

이론

이 보기는 틀렸다. 분자·분모가 뒤집힌 DOL의 역수로, 고정비가 있으면 1보다 작게 나온다.
