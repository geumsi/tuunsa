올해 주당배당금 1,000원, 배당성장률 5%, 요구수익률 10%일 때 항상성장모형에 따른 주가는?

정답과 해설 보기

정답 2번 21,000원

개념

항상성장모형(고든모형)은 배당이 매년 일정한 비율로 성장한다고 보고 주가를 구한다. 올해 배당을 먼저 다음 기 배당으로 바꾸는 것이 첫 단계다.

P0 = D1 / (k − g) = D0 × (1 + g) / (k − g)
  • P0 = 현재 적정주가
  • D0 = 올해(직전) 주당배당금, D1 = 다음 기 주당배당금 = D0 × (1 + g)
  • k = 요구수익률(할인율), g = 배당의 일정한 성장률
  • k > g일 때만 성립한다. g = 0이면 제로성장모형 P0 = D / k가 된다.
  • 예: D0 2,000원, g 4%, k 9%면 D1 = 2,080원, P0 = 2,080 / 0.05 = 41,600원이다.

해설

d1 = 1,000 × 1.05 = 1,050원이고, P = 1,050 / (0.10 − 0.05) = 21,000원이다.

d1: 다음 기 주당배당금 = d0 × (1 + g) · P: 현재 적정주가

암기

  • P = D₀(1+g)/(k−g)
    P: 현재 적정주가 · D₀: 올해(직전) 주당배당금 · g: 배당의 일정한 성장률 · k: 요구수익률(할인율)
  • 올해 배당이 주어지면 먼저 (1+g)를 곱한다

실무에서는

  • 리포트의 배당수익률은 과거 지급액 기준인 경우가 많아 밸류에이션에는 예상 배당으로 바꿔 쓴다.
  • 요구수익률과 성장률이 가까워지면 분모가 작아져 주가가 비현실적으로 커지므로 g < k인지 항상 확인한다.
