EV/EBITDA에서 EV와 EBITDA의 구성으로 옳은 것은?

  1. EV = 시가총액 + 순차입금, EBITDA = 영업이익 + 감가상각비
  2. EV = 시가총액 − 순차입금, EBITDA = 순이익 + 감가상각비
  3. EV = 자기자본 + 부채, EBITDA = 매출액 − 감가상각비
  4. EV = 시가총액, EBITDA = 영업이익
정답과 해설 보기

정답 1번 EV = 시가총액 + 순차입금, EBITDA = 영업이익 + 감가상각비

개념

EV/EBITDA(Enterprise Value / EBITDA, 기업가치 대비 EBITDA 배수)는 기업 전체 가치가 현금성 영업이익의 몇 배인지 보는 상대가치 지표다. 자본구조나 감가상각 방식이 달라도 비교하기 쉽다.

EV/EBITDA = (시가총액 + 순차입금) / (영업이익 + 감가상각비)
  • EV(Enterprise Value, 기업가치) = 기업가치 = 시가총액(주주가치) + 순차입금(채권자가치)
  • 순차입금 = 총차입금 − 현금성자산
  • EBITDA(Earnings Before Interest, Taxes, Depreciation and Amortization, 이자·법인세·감가상각비 차감 전 이익) = 이자·세금·감가상각 전 이익 = 영업이익 + 감가상각비
  • 주당가치 = 시가총액 / 발행주식수

해설

EV는 주주가치(시가총액)와 채권자가치(순차입금)의 합이고, EBITDA는 영업이익에 감가상각비를 더한 이자·세금·상각 전 이익이다.

암기

  • EV = 시가총액 + 순차입금
  • 순차입금 = 총차입금 − 현금성자산
  • EBITDA = 영업이익 + 감가상각비

실무에서는

  • M&A(Mergers and Acquisitions, 인수합병) 가격 협상과 사모펀드 실무에서 가장 많이 쓰는 배수다.
  • EV는 회사를 통째로 사서 빚까지 갚을 때 드는 돈이고, EBITDA는 감가상각 방식·세율·차입 구조의 영향을 덜 받는다.
  • 자본구조가 다른 기업 비교, 감가상각이 큰 설비 산업 평가에 PER(Price Earnings Ratio, 주가수익비율) 대신 쓴다.

실제 사례 · 2015홈플러스 LBO 인수가

MBK파트너스 컨소시엄은 2015년 홈플러스를 7조2000억원에 인수하며 약 5조원을 홈플러스 명의 대출로 조달했다고 보도됐다. 인수자 입장에서 회사의 값은 주식 대금만이 아니라 떠안는 빚까지 포함한 금액이다. → EV(시가총액 + 순차입금)가 M&A·PE(Private Equity, 사모투자(사모펀드 운용사)) 가격 협상의 기준이 되고, 이를 EBITDA와 비교해 몇 배에 샀는지 평가한다.

보기별 해설

1EV = 시가총액 + 순차입금, EBITDA = 영업이익 + 감가상각비정답
용어

EV/EBITDA는 기업 전체가 영업현금흐름의 몇 배에 거래되는지를 보는 배수다.

이론

이 보기가 정답이다. 분자는 시가총액과 순차입금의 합, 분모는 영업이익과 감가상각비의 합이다.

실무

통신·인프라처럼 감가상각이 큰 업종에서 PER보다 선호된다.

2EV = 시가총액 − 순차입금, EBITDA = 순이익 + 감가상각비
용어

순차입금은 총차입금에서 현금 및 현금성자산을 뺀 값이다.

이론

이 보기는 틀렸다. 기업 전체를 인수하면 순부채까지 떠안으므로 순차입금은 더하며, EBITDA도 순이익이 아니라 영업이익에서 출발한다.

실무

순현금 기업은 순차입금이 음수라 EV가 시가총액보다 작아 EV/EBITDA상 싸게 보인다.

3EV = 자기자본 + 부채, EBITDA = 매출액 − 감가상각비
용어

장부가 기준 자기자본 + 부채는 장부상 총자산과 같다.

이론

이 보기는 틀렸다. EV는 장부가가 아닌 시가총액과 순차입금을 쓰고, EBITDA는 매출액에서 상각비를 빼는 것이 아니라 영업이익에 감가상각비를 더한다.

실무

EV는 시장가격 기반이라 주가가 오르면 함께 커지므로 장부가 지표인 PBR(Price Book-value Ratio, 주가순자산비율)과 구분한다.

4EV = 시가총액, EBITDA = 영업이익
용어

시가총액은 주가 × 발행주식수로 주주 몫만의 가치다.

이론

이 보기는 틀렸다. 시가총액만으로는 채권자 몫이 빠지고, 영업이익에는 감가상각비가 이미 차감돼 EBITDA가 아니다.

실무

분자와 분모의 귀속 주체를 맞추지 않으면 부채가 많은 기업이 지나치게 싸게 보인다.
