수정듀레이션(힉스 듀레이션)의 공식으로 옳은 것은?

  1. 듀레이션 × (1 + 만기수익률)
  2. 듀레이션 / (1 + 만기수익률)
  3. (1 + 만기수익률) / 만기수익률
  4. 듀레이션 / 만기
정답과 해설 보기

정답 2번 듀레이션 / (1 + 만기수익률)

개념

수정듀레이션(힉스 듀레이션)은 만기수익률이 1단위 변할 때 채권가격이 몇 % 변하는지 나타내는 가격 민감도다.

MD = D / (1 + y)
ΔP/P ≈ −MD × Δy
  • MD = 수정듀레이션(힉스 듀레이션), D = 맥컬레이 듀레이션
  • y = 만기수익률(연 m회 이자면 1 + y/m으로 나눈다)
  • ΔP/P = 채권가격 변동률, Δy = 만기수익률 변화(1%p = 0.01)
영구채: D = (1 + y) / y, MD = 1 / y
  • 수정듀레이션은 항상 맥컬레이 듀레이션보다 작다.

해설

수정듀레이션은 매콜리 듀레이션을 (1 + 만기수익률)로 나눈 값이다. 채권가격변동률 ≈ −수정듀레이션 × 수익률 변화로 쓴다.

암기

  • 수정듀레이션 = D / (1 + y), 연 m회 이자면 (1 + y/m)으로 나눔
  • 영구채 듀레이션 = (1 + y) / y
  • 영구채 수정듀레이션 = 1 / y

실무에서는

  • 매콜리 듀레이션은 회수기간 개념이라 년 단위로 읽히고, 수정듀레이션은 가격 변동률로 바로 환산되어 실무 보고서에서 더 자주 쓴다.
  • 금리 수준이 바뀌면 같은 채권의 수정듀레이션도 바뀌므로 보고 시점마다 다시 계산한다.

보기별 해설

1듀레이션 × (1 + 만기수익률)
용어

듀레이션에 (1 + y)를 곱한 값이다.

이론

이 보기는 오답이다. 곱하면 매콜리 듀레이션보다 큰 값이 되어 가격민감도를 과대평가한다.

실무

수정듀레이션 < 매콜리 듀레이션이라는 대소관계로 공식 방향을 검산할 수 있다.

2듀레이션 / (1 + 만기수익률)정답
용어

수정듀레이션은 수익률 1%p 변화에 대한 채권가격 변동률을 나타내는 지표다.

이론

이 보기가 정답이다. 매콜리 듀레이션을 (1 + 만기수익률)로 나눠 구한다.

실무

채권형 펀드 운용보고서나 ETF(Exchange Traded Fund, 상장지수펀드) 설명서의 '듀레이션'은 대개 수정듀레이션이다.

3(1 + 만기수익률) / 만기수익률
용어

(1 + y) / y는 만기가 없는 영구채의 매콜리 듀레이션 공식이다.

이론

이 보기는 오답이다. 수정듀레이션 공식이 아니라 영구채 듀레이션 공식이다.

4듀레이션 / 만기
용어

듀레이션을 만기로 나눈 값은 회수기간이 만기 대비 얼마나 짧은지 보는 비율일 뿐이다.

이론

이 보기는 오답이다. 가격민감도를 나타내는 수정듀레이션이 아니며, 수정듀레이션의 분모는 (1 + 만기수익률)이다.

실무

민감도 지표로는 수정듀레이션 외에 볼록성, 실효듀레이션(옵션부채권), PVBP(Price Value of a Basis Point, 금리 1bp 변동 시 가격 변화)가 함께 쓰인다.
