정답 1번 약 1.91년

개념

맥컬레이 듀레이션은 각 현금흐름이 들어오는 시점을 그 현금흐름의 현재가치 비중으로 가중평균한 값이다.

D = Σ [t × CF_t / (1 + y)ᵗ] / P
  • D = 맥컬레이 듀레이션(년)
  • t = 현금흐름이 들어오는 시점(년)
  • CF_t = t 시점의 현금흐름(이자, 만기에는 이자 + 원금)
  • y = 만기수익률, P = 채권가격(모든 CF_t 현재가치의 합)
  • 이표채는 중간 이자 때문에 듀레이션 < 만기, 할인채·복리채는 듀레이션 = 만기다.
  • 예: 표면이자율 8%, 만기수익률 8%, 2년 만기 채권은 가격이 액면과 같고 D ≈ 1.93년이다.

해설

맥컬레이 듀레이션은 현금흐름 현재가치로 가중평균한 회수 시점이다. 표면이자율 = 만기수익률이라 가격은 10,000원이다.

  • 1년차 PV(Present Value, 현재가치) ≈ 909.1원, 2년차 PV ≈ 9,090.9원
  • D = (1 × 909.1 + 2 × 9,090.9) ÷ 10,000 ≈ 1.91년
    D: 맥컬레이 듀레이션(년)

암기

  • D = Σ(t × 현금흐름 PV) ÷ 채권가격
    D: 맥컬레이 듀레이션(년) · t: 현금흐름이 들어오는 시점(년) · PV: 현재가치
  • 이표채 듀레이션 < 만기, 할인채 = 만기
  • 수정듀레이션 = 맥컬레이 ÷ (1 + y)
    y: 만기수익률

계산기 꿀팁

D = Σ t·PV(CF_t) ÷ P

D: 맥컬레이 듀레이션(년) · t: 현금흐름이 들어오는 시점(년) · PV(CF_t): t 시점 현금흐름의 현재가치 · P: 채권가격(현금흐름 현재가치의 합)

일반 계산기

  1. MC
  2. 1000 ÷ 1.1 = M+ → 909.09 (1년차 PV × 1)
    PV: 현재가치
  3. 11000 ÷ 1.21 = → 9090.91 → × 2 = M+ → 18181.82
  4. MR → 19090.91
  5. ÷ 10000 = → 1.909

공학용 계산기

( 1000 ÷ 1.1 + 2 × 11000 ÷ 1.1 x² ) ÷ 10000 SHIFT = → 1.909

꿀팁 가격이 액면(10,000)이면 분모를 따로 계산할 필요가 없다. 또 만기 2년 이표채의 듀레이션은 '2 − (1년차 PV ÷ 가격)'으로도 구할 수 있다: 2 − 909.1/10,000 = 1.909. 이표채 듀레이션은 반드시 만기보다 짧으니 2년 이상 보기는 바로 지운다.

실무에서는

  • 듀레이션은 가중평균 회수 시점이자 금리 민감도다.
  • 운용역은 부채 듀레이션에 자산 듀레이션을 맞춰(면역전략) 금리 변동 위험을 줄인다.

실제 사례 · 2022영국 LDI 연기금 위기

영국 확정급여형 연기금은 부채 듀레이션에 맞추려 LDI(Liability-Driven Investment, 부채연계투자) 펀드로 장기국채를 약 1.5조파운드 규모로 운용했다. 2022년 9월 미니예산 뒤 30년 국채금리가 하루 만에 67bp 넘게 뛰자 담보 매도 악순환 우려가 커졌고, 영란은행이 9월 28일 장기국채 매입에 나섰다. → 듀레이션으로 부채를 면역화해도 레버리지 파생을 쓰면 금리 급등 때 유동성 위험이 생긴다.
