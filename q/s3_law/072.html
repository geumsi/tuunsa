자본시장법·금융위원회 규정 · 50/51

  1. 검사실시 → 사전조사 → 검사보고 → 검사결과조치 → 사후보고
  2. 사전조사 → 검사실시 → 검사보고 → 검사결과조치 → 사후보고

정답과 해설 보기

정답 2번 사전조사 → 검사실시 → 검사보고 → 검사결과조치 → 사후보고

개념

금융기관 검사는 금융감독원이 금융기관의 업무와 재산 상황을 점검하는 절차다.

  • 1 사전조사: 대상 기관 자료를 받아 검사 중점과 범위를 정한다.
  • 2 검사실시: 검사반이 현장에 나가거나 자료를 받아 실제로 점검한다.
  • 3 검사보고: 검사 종료 뒤 결과를 정리해 보고한다.
  • 4 검사결과조치: 위법·부당 행위에 제재·시정 조치를 한다(금융위 심의 원칙, 위임사항은 금감원장).
  • 5 사후보고: 조치의 이행 결과를 보고받아 확인한다.

해설

금융기관 검사는 사전조사 → 검사실시 → 검사보고 → 검사결과조치 → 사후보고 순으로 진행된다.

암기

  • 사전조사 → 검사실시 → 검사보고 → 검사결과조치 → 사후보고
  • 흐름: 준비 → 실행 → 보고 → 조치 → 이행 확인

실무에서는

  • 사전조사에서 회사 보고서와 자료를 분석해 중점 점검 사항을 정하고, 현장 검사 후 보고서를 써서 조치를 정하고, 이행 여부를 사후에 확인한다.
  • 검사 통보를 받으면 준법감시 부서가 자료 요청 목록을 각 부서에 배분하고 검사 기간 중 질의 대응을 총괄한다.

가상 사례검사 진행 순서

  • A증권이 금감원 정기검사 통보를 받았다.
  • 금감원은 사전조사로 중점 점검 사항을 정하고, 현장검사 후 검사보고서를 써서 조치를 정한다. 이후 지적 사항 이행 여부를 다시 확인한다.
  • A증권 준법감시부는 자료 요청 목록을 부서별로 나누고 질의 대응을 총괄했다.

→ 사전조사 → 검사 실시 → 보고·조치 → 사후관리 순서다.

보기별 해설

1검사실시 → 사전조사 → 검사보고 → 검사결과조치 → 사후보고
용어

검사실시는 검사반이 금융기관에 나가거나 자료를 받아 실제로 업무와 재산 상황을 점검하는 단계다.

이론

이 보기는 틀렸다. 사전조사로 대상과 중점 사항을 정한 뒤에 검사를 실시하므로 검사실시가 앞설 수 없다.

실무

금감원은 착수 전 서면 자료로 사전조사를 하고 그 결과로 현장검사 인원과 기간을 정한다.

2사전조사 → 검사실시 → 검사보고 → 검사결과조치 → 사후보고정답
용어

금융기관 검사 절차는 금융감독원이 금융기관을 검사하고 결과를 처리하는 단계별 순서다.

이론

이 보기가 정답이다. 준비하고, 실시하고, 보고하고, 조치하고, 이행을 사후 보고하는 논리적 순서다.

실무

금융회사는 사후보고 단계에서 지적사항 이행 결과를 기한 안에 내야 하고, 미이행은 추가 제재 사유가 된다.

3사전조사 → 검사보고 → 검사실시 → 사후보고 → 검사결과조치
용어

검사보고는 검사 종료 후 검사반이 결과를 정리해 보고하는 단계다.

이론

이 보기는 틀렸다. 검사보고가 검사실시보다 앞설 수 없고, 조치가 있어야 이행을 보고하므로 사후보고도 조치보다 먼저 올 수 없다.

4검사실시 → 검사보고 → 사전조사 → 검사결과조치 → 사후보고
용어

사전조사는 검사 전에 대상 금융기관 자료를 받아 검사 중점과 범위를 정하는 단계다.

이론

이 보기는 틀렸다. 맨 앞이어야 할 사전조사를 검사실시와 검사보고 뒤에 두었다.

실무

사전조사 때 금융회사가 내는 자료의 품질이 검사 범위를 좌우해 내부통제 부서는 평소 자료 관리 체계를 갖춰 둔다.
