분산투자기법 · 3/16

다음 중 다기간 수익률(연평균수익률) 측정방법이 아닌 것은?

  1. 산술평균법
  2. 기하평균수익률
  3. 내부수익률
  4. 단일기간 보유수익률
정답과 해설 보기

정답 4번 단일기간 보유수익률

개념

수익률은 한 기간만 보는 단일기간 수익률과, 여러 기간을 연평균으로 바꾼 다기간 수익률로 나뉜다.

단일기간 보유수익률 = (기말가치 − 기초가치 + 현금수입) / 기초가치
  • 단일기간 수익률은 보유기간이 제각각이라 그대로 비교하기 어렵다. 다기간 수익률은 연평균이라 비교할 수 있다.
  • 다기간 수익률 측정법 3가지: 산술평균, 기하평균(시간가중수익률), 내부수익률(금액가중수익률)
산술평균 = (r1 + r2 + … + rn) / n
기하평균 = [(1 + r1)(1 + r2)…(1 + rn)]^(1/n) − 1
  • r1…rn = 각 기간 수익률, n = 기간 수
  • 내부수익률 = 모든 현금흐름의 현재가치 합을 0으로 만드는 할인율

해설

단일기간 보유수익률은 측정 기간이 제각각이라 그대로는 비교하기 어렵다. 다기간 수익률은 산술평균·기하평균·내부수익률로 측정한다.

암기

  • 다기간 수익률: 산술평균·기하평균(시간가중)·내부수익률(금액가중)
  • 단일기간 보유수익률 = (기말가치 − 기초가치 + 현금수입) / 기초가치

실무에서는

  • 연평균수익률은 어떤 방법으로 환산했는지에 따라 숫자가 다르다.
  • 공모펀드 성과 공시는 기하평균 방식의 시간가중수익률이 표준이다.
  • 사모펀드·벤처투자처럼 자금 투입 시점이 중요한 영역은 내부수익률을 주로 쓴다.

보기별 해설

1산술평균법
용어

산술평균수익률은 기간별 수익률을 단순 합산해 기간 수로 나눈 값이다.

이론

다기간 수익률 측정방법이라 정답이 아니다. 계산은 쉽지만 수익률 변동이 클수록 실제 성과를 과대평가한다.

실무

다음 기간의 기대수익률을 추정할 때는 산술평균이 적합하다고 본다.

2기하평균수익률
용어

기하평균수익률은 ((1+R1)(1+R2)…(1+Rn))^(1/n) − 1로, 복리로 연결한 연평균 수익률이다.

이론

다기간 수익률 측정방법이라 정답이 아니다. 시간가중수익률에 해당하며 과거 실제 성과를 정확하게 나타낸다.

실무

펀드 장기 성과의 연환산 수익률(CAGR)이 기하평균이다.

3내부수익률
용어

내부수익률(IRR)은 현금유입의 현재가치와 현금유출의 현재가치를 같게 만드는 할인율이다.

이론

다기간 수익률 측정방법이라 정답이 아니다. 투자금액의 크기와 시점을 반영하는 금액가중수익률이다.

실무

적립식 투자나 사모펀드처럼 자금이 여러 번 들고 나는 투자의 성과를 IRR로 평가한다.

4단일기간 보유수익률정답
용어

단일기간 보유수익률은 한 기간 동안의 가치 변화와 현금수입을 기초가치로 나눈 수익률이다.

이론

이 보기가 정답이다. 기간이 다른 수익률끼리는 비교가 어려워 다기간 측정방법으로 환산해야 한다.

실무

3개월 수익률과 3년 누적 수익률을 그대로 비교하지 않도록 고객 보고서에서는 연환산 수익률로 보여준다.
