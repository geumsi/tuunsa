순소득승수의 산식으로 옳은 것은?

  1. 순운용소득 / 총투자액
  2. 총투자액 / 순운용소득
  3. 순운용소득 / 부채상환액
  4. 저당대출원금 / 부동산가격
정답과 해설 보기

정답 2번 총투자액 / 순운용소득

개념

순소득승수는 총투자액이 1년 순운용소득의 몇 배인지 보는 간편분석 지표다. 투자액을 몇 년 치 순소득으로 회수하는지 보여 줘 자본회수기간으로 쓴다.

순소득승수 = 총투자액 / 순운용소득
투자이율 = 순운용소득 / 총투자액 (순소득승수의 역수)
  • 총투자액 = 부동산 취득에 들어간 전체 금액(자기자본 + 차입금)
  • 순운용소득 = 유효총소득에서 영업경비를 뺀 1년 소득
  • 같은 계열 비율: DSCR = 순운용소득 / 부채상환액, LTV = 저당대출원금 / 부동산가격
  • 예: 총투자액 10억 원, 순운용소득 1억 원이면 순소득승수 10배, 투자이율 10%다.

해설

순소득승수 = 총투자액 / 순운용소득이다. 투자액을 몇 년 치 순소득으로 회수하는지 보여줘 자본회수기간으로 쓰인다.

암기

  • 순소득승수 = 총투자액 / 순운용소득
  • 투자이율 = 순운용소득 / 총투자액 (역수)
  • DSCR(Debt Service Coverage Ratio, 부채상환비율(부채감당률)) = 순운용소득 / 부채상환액
  • LTV(Loan To Value, 담보인정비율) = 저당대출원금 / 부동산가격

실무에서는

  • 순소득승수는 캡레이트의 역수 개념이라 매물 가격을 가늠하는 눈대중으로 쓴다.
  • '이 빌딩은 순소득의 몇 배에 나왔다'고 말할 때 이 지표다.
  • 투자액을 소득으로 나누면 회수 햇수가 나온다고 기억하면 산식 방향이 헷갈리지 않는다.

가상 사례순소득승수로 가격 가늠

  • 매도자가 오피스 빌딩을 1,000억원에 내놓았고 연 순운용소득은 50억원이다.
  • 순소득승수 = 1,000 / 50 = 20배, 순소득으로 20년이면 투자액을 회수한다는 뜻이다.
  • 주변 거래가 18배 수준이면 B자산운용은 가격이 비싸다고 보고 협상한다.

→ 분자가 총투자액, 분모가 순운용소득이다.

보기별 해설

1순운용소득 / 총투자액
용어

순운용소득(NOI)을 총투자액으로 나눈 값은 투자이율이다.

이론

이 보기는 틀렸다. 분자와 분모가 뒤집힌 투자이율 산식이다.

실무

결과 단위로 검산한다. 승수는 10배·15배, 이율은 5%·7%처럼 나온다.

2총투자액 / 순운용소득정답
용어

순운용소득은 유효총소득에서 영업경비를 뺀 금액이다.

이론

이 보기가 정답이다. 총투자액을 1년 순운용소득으로 나누므로 회수에 필요한 햇수를 뜻하며, 값이 작을수록 유리하다.

실무

총투자액 100억 원, 순운용소득 5억 원이면 승수 20배로 단순 계산상 20년에 원금을 회수한다.

3순운용소득 / 부채상환액
용어

순운용소득을 연간 원리금으로 나눈 값은 부채상환비율(DSCR)이다.

이론

이 보기는 틀렸다. 대출 원리금을 영업소득으로 몇 배 감당하는지 보는 DSCR이며, 높을수록 상환능력이 크다.

실무

DSCR은 대출 약정의 유지 조건으로 자주 들어간다.

4저당대출원금 / 부동산가격
용어

저당대출원금을 부동산가격으로 나눈 값은 대출비율(LTV)이다.

이론

이 보기는 틀렸다. LTV는 타인자본 비중을 보는 자본구조 지표라 소득을 쓰지 않는다.

실무

산식에 소득 항목이 없으면 LTV로 바로 걸러낼 수 있다.
