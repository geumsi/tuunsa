주식투자운용 · 11/21

전략적 자산배분의 실행과정을 순서대로 나열한 것은?

  1. 자산집단 선택 → 투자목적 파악 → 최적자산구성 → 기대수익 추정
  2. 투자목적·제약조건 파악 → 자산집단 선택 → 기대수익·위험·상관관계 추정 → 최적자산구성 선택
  3. 기대수익 추정 → 자산집단 선택 → 투자목적 파악 → 최적자산구성
  4. 최적자산구성 → 자산집단 선택 → 기대수익 추정 → 투자목적 파악
정답과 해설 보기

정답 2번 투자목적·제약조건 파악 → 자산집단 선택 → 기대수익·위험·상관관계 추정 → 최적자산구성 선택

개념

전략적 자산배분은 장기 투자목적에 맞는 자산구성(정책 포트폴리오)을 정하는 과정이며, 앞 단계의 결과가 다음 단계의 입력이 된다.

  • 1단계: 투자목적과 투자제약조건 파악
  • 2단계: 자산집단 선택
  • 3단계: 자산집단별 기대수익·위험·상관관계 추정
  • 4단계: 최적자산구성 선택
  • 기대수익은 자산집단이 정해져야 추정할 수 있고, 자산집단은 목적이 정해져야 고를 수 있다.

해설

전략적 자산배분은 투자목적·제약조건 파악부터 시작해 최적자산구성 선택으로 끝난다. 목적이 정해져야 자산군을 고르고, 자산군이 정해져야 기대수익을 추정할 수 있다.

암기

  • 목적·제약 파악 → 자산집단 선택 → 기대수익·위험·상관관계 추정 → 최적자산구성

실무에서는

  • 이 순서는 연기금·기관의 투자정책서(IPS) 작성 순서와 거의 같다.
  • 첫 단계에서 유동성 요구, 투자 가능 자산 범위, 손실 허용 한도를 문서로 확정한다.
  • 최적자산구성은 마지막 결과물이며 매년 가정을 다시 점검해 갱신한다.

가상 사례투자정책서부터 쓰기

  • J재단은 기금운용을 맡기기 전 투자정책서에 연 4% 지출 필요, 손실 허용 -10%, 투자 가능 자산 범위를 먼저 적었다.
  • 그다음 자산군별 기대수익률·위험을 추정하고, 마지막에 주식 40%·채권 50%·대체 10%의 최적 구성을 정했다.

→ 전략적 자산배분은 투자자 분석 → 자산 선택 → 기대수익률·위험 추정 → 최적 구성 순으로 진행한다.

보기별 해설

1자산집단 선택 → 투자목적 파악 → 최적자산구성 → 기대수익 추정
용어

자산집단 선택은 주식·채권·대체투자 등 투자 대상 자산군을 정하는 단계다.

이론

이 보기는 오답이다. 목적을 모르는 상태에서 자산군을 고를 수 없고, 기대수익 추정도 최적자산구성보다 앞서야 한다.

실무

고객 상담에서도 상품부터 고르지 않고 목적·기간·유동성 필요를 먼저 확인하는 적합성 원칙과 같은 순서다.

2투자목적·제약조건 파악 → 자산집단 선택 → 기대수익·위험·상관관계 추정 → 최적자산구성 선택정답
용어

투자목적·제약조건 파악은 목표수익률·위험허용도와 투자기간·유동성·법규 같은 제약을 정하는 단계다.

이론

이 보기가 정답이다. 목적과 제약에 맞는 자산군을 고르고, 자산군별 기대수익·위험·상관관계를 추정해 최적 비중을 정한다.

실무

제약조건에는 세금, 법규상 투자한도, 유동성 필요 등이 들어간다.

3기대수익 추정 → 자산집단 선택 → 투자목적 파악 → 최적자산구성
용어

기대수익 추정은 자산집단별 기대수익률·위험·상관관계를 계산해 최적화의 입력값을 만드는 단계다.

이론

이 보기는 오답이다. 기대수익 추정은 자산집단을 정한 뒤에야 할 수 있고, 투자목적 파악이 모든 단계의 출발점이다.

실무

추정할 자산군이 정해지지 않으면 공분산 행렬도 만들 수 없다.

4최적자산구성 → 자산집단 선택 → 기대수익 추정 → 투자목적 파악
용어

최적자산구성 선택은 효율적 프런티어에서 투자자 위험성향에 맞는 포트폴리오를 고르는 단계다.

이론

이 보기는 오답이다. 앞 단계의 결과를 모두 입력받는 마지막 단계라 맨 앞에 올 수 없다. 실제 과정을 거꾸로 나열했다.

실무

모델 포트폴리오를 먼저 정해 놓고 고객 목적을 끼워 맞추는 영업은 적합성 원칙 위반 소지가 있다.
