리스크관리 · 29/31 계산

자산 A의 VaR는 30억원, 자산 B의 VaR는 40억원이고 두 자산 수익률의 상관계수는 0.5이다. 두 자산으로 구성된 포트폴리오의 VaR는 약 얼마인가?

  1. 약 60.8억원
  2. 70억원
  3. 50억원
  4. 10억원
정답과 해설 보기

정답 1번 약 60.8억원

개념

포트폴리오 VaR는 개별 자산의 VaR를 상관계수로 결합한 값이다. 상관계수가 1보다 작으면 분산효과로 개별 VaR 합보다 작아진다.

VaR_P = √(VaR_A² + VaR_B² + 2 × ρ × VaR_A × VaR_B)
  • VaR_A, VaR_B = 각 자산의 개별 VaR
  • ρ = 두 자산 수익률의 상관계수(−1 ~ +1). 낮을수록 VaR_P가 작다.
  • ρ = 1이면 VaR_A + VaR_B(단순합), ρ = 0이면 √(VaR_A² + VaR_B²), ρ = −1이면 |VaR_A − VaR_B|
분산효과 = (VaR_A + VaR_B) − VaR_P
  • 예: 개별 VaR 5억·12억, ρ = 0 → √(25 + 144) = 13억원, 분산효과 4억원

해설

포트폴리오 VaR는 개별 VaR와 상관계수로 구하며, 상관계수가 1보다 작으면 개별 VaR 합보다 작아진다.

  • √(30² + 40² + 2 × 0.5 × 30 × 40) = √3,700 ≈ 60.8억원
  • 분산효과 = 70억 − 60.8억 ≈ 9.2억원

암기

  • VaR(Value at Risk, 최대예상손실)_P = √(VaR_A² + VaR_B² + 2ρ·VaR_A·VaR_B)
  • ρ = 1 → 단순합, ρ = 0 → 교차항 0, ρ = −1 → |차이|

계산기 꿀팁

VaR_P = √(VaR_A² + VaR_B² + 2ρ·VaR_A·VaR_B)

일반 계산기

  1. MC
  2. 30 × 30 = M+ → 900
  3. 40 × 40 = M+ → 1600
  4. 2 × 0.5 × 30 × 40 = M+ → 1200
  5. MR → 3700
  6. √ → 60.83

공학용 계산기

√■ 30 x² + 40 x² + 2 × 0.5 × 30 × 40 ▶ SHIFT = → 60.83

꿀팁 루트 안의 세 항을 M+로 모두 쌓고 MR √ 한 번이면 끝난다. 상관계수가 0이면 3:4:5 직각삼각형처럼 50이 바로 나오니 보기 검산에 쓴다.

실무에서는

  • 사업부별 VaR 합으로 한도를 배분하면 분산효과만큼 자본을 과다하게 묶게 된다.
  • 그래서 전사 VaR는 상관관계를 반영해 따로 계산하고, 한계 VaR로 다시 나눈다.
  • 위기 때 상관계수가 1에 가까워져 분산효과가 사라진다는 점이 스트레스 테스트의 출발점이다.

가상 사례분산효과와 VaR 한도

  • A증권은 주식부문 VaR 30억원, 채권부문 VaR 40억원을 단순 합산해 70억원 한도를 잡았다.
  • 상관계수 0.5를 반영하면 전사 VaR는 약 60.8억원으로, 9억원 남짓의 자본이 불필요하게 묶여 있었다.

→ 상관계수가 1보다 작으면 포트폴리오 VaR는 개별 VaR 합보다 작다.

단순합은 분산효과를 인정받지 못할 때 쓰는 가장 보수적인 추정치다.

루트 안에 항이 세 개인지 확인하면 교차항 누락을 막는다.

실무

완전 음의 상관은 이론적 한계이며 실제 자산 사이에서는 거의 없다.
