KMV의 부도거리(DD) 공식으로 옳은 것은? (A: 기업 미래자산가치, D: 부채금액, σ: 자산가치 표준편차)

  1. DD = (A − D) / σ
  2. DD = (D − A) / σ
  3. DD = A / D
  4. DD = σ / (A − D)
정답과 해설 보기

정답 1번 DD = (A − D) / σ

개념

KMV의 EDF 모형은 기업 자산가치가 부도점(부채) 아래로 떨어질 확률을 구한다. 자산가치가 부채보다 작아지면(A < D) 부도로 본다.

DD = (A − D) / σ
  • DD = 부도거리. 자산가치가 부도점에서 표준편차 몇 개만큼 떨어져 있는지
  • A = 기업의 미래 자산가치(기댓값)
  • D = 부채금액(부도점)
  • σ = 자산가치의 표준편차
  • DD가 클수록 안전하다. 작을수록 EDF(부도확률)가 커져 신용위험이 높다.
  • 이론적 EDF는 표준정규분포에서 DD 표준편차를 넘어 하락할 확률이다. 이를 실제 부도율에 대응시켜 실증적 EDF를 만들고, 부도확률 예측에는 실증적 EDF를 쓴다. 둘은 같지 않다.
  • 재무정보가 아닌 현재 주가를 활용하고, 콜옵션 논리를 응용한다.
  • 예: A 200억원, D 140억원, σ 20억원 → DD = (200 − 140) / 20 = 3 표준편차

해설

부도거리는 DD = (A − D)/σ다. 자산가치가 부채보다 작아지면(A < D) 부도가 발생한다고 가정한다.

암기

  • DD(Distance to Default, 부도거리) = (A − D) / σ
  • DD ↓ → EDF(Expected Default Frequency, 기대부도빈도) ↑ → 신용위험 ↑

실무에서는

  • KMV(Kealhofer, McQuown, Vasicek, KMV 부도예측 모형(개발자 이름 머리글자)) 모형은 주식을 자산에 대한 콜옵션으로 보고, 자산가치가 부채 아래로 떨어지면 주주가 회사를 포기한다는 논리로 부도확률을 구한다.
  • 자산 변동성이 큰 기업은 같은 여유 폭이어도 부도거리가 짧다.
  • 드물게 바뀌는 신용등급과 달리 주가 기반이라 매일 갱신되어 조기경보 지표로 쓰인다.

보기별 해설

1DD = (A − D) / σ정답
용어

부도거리(DD, Distance to Default)는 기업 자산가치가 부도점에서 몇 표준편차 떨어져 있는지를 나타낸 값이다.

이론

이 식이 옳으므로 정답이다. 실무 KMV 모형에서 D는 단기부채 + 장기부채의 50% 같은 부도점으로 쓴다.

실무

은행 여신심사에서 상장기업의 시장기반 부도위험 지표로 활용된다.

2DD = (D − A) / σ
용어

(D − A)/σ는 부도거리의 부호를 뒤집은 값이다.

이론

이 식은 틀렸다. 건전한 기업일수록 값이 음수가 되어 '거리'의 의미가 반대가 된다.

3DD = A / D
용어

A/D는 자산 대비 부채의 배수로, 표준편차를 반영하지 않은 단순 비율이다.

이론

이 식은 틀렸다. 부도거리는 자산가치 변동성(σ)을 반영해 표준편차 단위로 표시해야 한다.

실무

같은 부채비율이라도 자산 변동성이 큰 기업이 더 위험하다는 점을 반영하는 것이 DD의 핵심이다.

4DD = σ / (A − D)
용어

σ/(A − D)는 부도거리의 역수다.

이론

이 식은 틀렸다. 분자와 분모가 뒤집혀 값이 클수록 오히려 위험한 지표가 된다.
