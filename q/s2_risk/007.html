리스크관리 · 7/31

자산 A의 VaR 30억원, 자산 B의 VaR 40억원, 두 자산 간 상관계수가 0일 때 포트폴리오 VaR는?

  1. 10억원
  2. 50억원
  3. 70억원
  4. 35억원
정답과 해설 보기

정답 2번 50억원

개념

포트폴리오 VaR(Value at Risk, 최대예상손실)는 개별 자산의 VaR를 상관계수로 결합한 값이다. 상관계수가 1보다 작으면 분산효과로 개별 VaR 합보다 작아진다.

VaR_P = √(VaR_A² + VaR_B² + 2 × ρ × VaR_A × VaR_B)
  • VaR_A, VaR_B = 각 자산의 개별 VaR
  • ρ = 두 자산 수익률의 상관계수(−1 ~ +1). 낮을수록 VaR_P가 작다.
  • ρ = 1이면 VaR_A + VaR_B(단순합), ρ = 0이면 √(VaR_A² + VaR_B²), ρ = −1이면 |VaR_A − VaR_B|
분산효과 = (VaR_A + VaR_B) − VaR_P
  • 예: 개별 VaR 5억·12억, ρ = 0 → √(25 + 144) = 13억원, 분산효과 4억원

해설

포트폴리오 VaR = √(30² + 40² + 2×0×30×40) = √2500 = 50억원이다. 단순합 70억원보다 작은 20억원이 분산효과다.

암기

  • 포트폴리오 VaR = √(VaR₁² + VaR₂² + 2ρ·VaR₁·VaR₂)
    VaR₁: 자산 1(A)의 개별 VaR · VaR₂: 자산 2(B)의 개별 VaR
  • ρ=1 → 단순합 · ρ=−1 → |차이| · ρ<1 → 단순합보다 작음
    ρ: 두 자산 수익률의 상관계수(−1 ~ +1)

실무에서는

  • 리스크관리팀은 전사 VaR를 낼 때 부서별 VaR를 단순히 더하지 않고 상관관계를 반영해 합산한다.
  • 위기 때는 자산 간 상관계수가 급격히 1에 가까워져 평상시 분산효과가 사라진다.

가상 사례부서 VaR를 그냥 더하지 않는 이유

  • A증권 주식부서 VaR 30억원, 채권부서 VaR 40억원을 단순 합산하면 70억원이다.
  • 리스크관리팀은 두 부서 손익의 상관관계를 반영해 전사 VaR를 50억원으로 보고했다.

→ 상관계수가 1보다 작으면 포트폴리오 VaR는 개별 VaR의 합보다 작아진다. 상관계수 0이면 √(30²+40²)=50.

보기별 해설

110억원
용어

10억원은 |40 − 30|으로, 상관계수 −1(완전 헤지)일 때의 포트폴리오 VaR다.

이론

10억원은 틀렸다. 문제의 상관계수는 −1이 아니라 0이다.

실무

상관계수 −1은 선물 헤지처럼 거의 완벽히 반대로 움직이는 포지션에서만 근사적으로 나타난다.

250억원정답
용어

50억원은 ρ = 0이라 교차항이 사라진 √(900 + 1600)의 값이다.

ρ: 두 자산 수익률의 상관계수(−1 ~ +1)
이론

50억원이 정답이다. 상관계수 0이면 √(VaR₁² + VaR₂²)이 된다.

VaR₁: 자산 1(A)의 개별 VaR · VaR₂: 자산 2(B)의 개별 VaR
실무

리스크관리 보고서는 사업부 VaR 합계와 전사 VaR의 차이를 '분산효과(diversification benefit)'로 따로 보고한다.

370억원
용어

70억원은 30 + 40으로, 상관계수 1(분산효과 없음)일 때의 값이다.

이론

70억원은 틀렸다. 상관계수가 1일 때만 단순합이 된다.

실무

개별 VaR를 단순 합산하면 위험을 보수적으로(과대) 측정하게 된다.

435억원
용어

35억원은 두 VaR의 단순평균((30+40)/2)이다.

이론

35억원은 틀렸다. 포트폴리오 VaR는 제곱합의 제곱근 꼴로 계산하며, 평균은 어떤 상관계수에서도 나오지 않는다.
