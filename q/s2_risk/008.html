리스크관리 · 8/31

두 자산으로 구성된 포트폴리오의 VaR에 대한 설명으로 옳지 않은 것은?

  1. 두 자산의 상관계수가 1이면 포트폴리오 VaR는 개별 VaR의 단순합과 같다.
  2. 포트폴리오 VaR는 두 자산 간 상관계수가 낮을수록 작아진다.
  3. 두 자산의 상관계수가 −1이면 포트폴리오 VaR는 개별 VaR 차이의 절댓값과 같다.
  4. 두 자산의 상관계수가 0이면 포트폴리오 VaR는 개별 VaR의 단순합과 같다.
정답과 해설 보기

정답 4번 두 자산의 상관계수가 0이면 포트폴리오 VaR는 개별 VaR의 단순합과 같다.

개념

포트폴리오 VaR는 개별 자산의 VaR를 상관계수로 결합한 값이다. 상관계수가 1보다 작으면 분산효과로 개별 VaR 합보다 작아진다.

VaR_P = √(VaR_A² + VaR_B² + 2 × ρ × VaR_A × VaR_B)
  • VaR_A, VaR_B = 각 자산의 개별 VaR
  • ρ = 두 자산 수익률의 상관계수(−1 ~ +1). 낮을수록 VaR_P가 작다.
  • ρ = 1이면 VaR_A + VaR_B(단순합), ρ = 0이면 √(VaR_A² + VaR_B²), ρ = −1이면 |VaR_A − VaR_B|
분산효과 = (VaR_A + VaR_B) − VaR_P
  • 예: 개별 VaR 5억·12억, ρ = 0 → √(25 + 144) = 13억원, 분산효과 4억원

해설

ρ = 0이면 포트폴리오 VaR는 √(VaR₁² + VaR₂²)이라 단순합보다 작다. 단순합이 되는 것은 ρ = 1일 때뿐이다.

  • 예: 개별 VaR 30·40 → 단순합 70이 아니라 50

암기

  • 포트폴리오 VaR(Value at Risk, 최대예상손실) = √(a² + b² + 2ρab)
  • ρ=1 → a+b · ρ=0 → √(a²+b²) · ρ=−1 → |a−b|
  • ρ 낮을수록 포트폴리오 VaR ↓

실무에서는

  • 상관계수 −1에 가까운 자산을 더하면 VaR가 오히려 줄어드는데, 이것이 선물 매도·인버스 포지션 헤지의 원리다.
  • 리스크위원회가 신규 자산 편입을 심의할 때 개별 위험보다 기존 포트폴리오와의 상관관계를 먼저 묻는 이유다.

가상 사례선물 매도로 VaR 줄이기

  • B자산운용 주식형 펀드는 시장 급락이 우려되자 코스피200 선물을 일부 매도했다.
  • 보유 주식과 선물 매도 포지션의 상관계수가 −1에 가까워 펀드 VaR가 크게 줄었다.

→ 두 자산 VaR는 상관계수가 낮을수록 작아지고, −1이면 두 VaR의 차이까지 줄어든다.

보기별 해설

1두 자산의 상관계수가 1이면 포트폴리오 VaR는 개별 VaR의 단순합과 같다.
용어

ρ = 1이면 √(a² + b² + 2ab) = a + b가 된다.

이론

옳은 진술이라 정답이 아니다. 두 자산이 완전히 같이 움직여 분산효과가 없다.

실무

규제 자본에서 위험 간 상관관계를 인정하지 않을 때 단순합산 방식을 쓰는 것과 같은 논리다.

2포트폴리오 VaR는 두 자산 간 상관계수가 낮을수록 작아진다.
용어

분산효과는 상관관계가 1보다 작은 자산을 결합할 때 전체 위험이 개별 위험의 합보다 작아지는 효과다.

이론

옳은 진술이라 정답이 아니다. 교차항 2ρ·VaR₁·VaR₂가 ρ에 비례하므로 ρ가 낮을수록 포트폴리오 VaR가 작아진다.

실무

자산배분 시 상관관계가 낮은 자산(채권·금·대체투자)을 섞는 근거가 된다.

3두 자산의 상관계수가 −1이면 포트폴리오 VaR는 개별 VaR 차이의 절댓값과 같다.
용어

ρ = −1이면 √(a² + b² − 2ab) = |a − b|가 된다.

이론

옳은 진술이라 정답이 아니다. 한쪽 손실을 다른 쪽 이익이 상쇄한다.

실무

두 VaR가 같고 ρ = −1이면 포트폴리오 VaR는 0이 되어 완전헤지 상태가 된다.

4두 자산의 상관계수가 0이면 포트폴리오 VaR는 개별 VaR의 단순합과 같다.정답
용어

ρ = 0은 두 자산 수익률 사이에 선형 관계가 없다는 뜻이다.

이론

이 진술은 틀렸으므로 정답이다. ρ = 0이면 교차항만 사라질 뿐 단순합보다 작다.

실무

'상관관계가 없다 = 분산효과가 없다'로 착각하기 쉬우나, 상관관계 0은 오히려 상당한 분산효과가 있는 상태다.
