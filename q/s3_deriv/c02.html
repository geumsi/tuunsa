정답과 해설 보기

정답 1번 약 4.04

개념

풋-콜 패리티는 같은 기초자산, 같은 행사가격, 같은 만기의 유럽형 콜과 풋 가격 사이에 성립하는 차익거래 없는 관계식이다.

C + K / (1 + r)ᵗ = P + S
단리 할인이면 C + K / (1 + r × t) = P + S
  • C = 콜옵션 가격, P = 풋옵션 가격
  • S = 현재 기초자산 가격, K = 행사가격
  • K / (1 + r)ᵗ = 행사가격의 현재가치 PV(K)(만기에 K를 주는 무위험채권)
  • r = 무위험이자율, t = 잔존만기(연 단위)
  • '콜 + 채권 = 풋 + 주식'으로 외우고 구할 항만 남기고 이항한다. 예: P = C + PV(K) − S
  • S = K여도 PV(K) < K라 콜이 풋보다 비싸다.

해설

풋-콜 패리티(C + PV(K) = P + S)에서 풋가격은 C + PV(K) − S다.

C: 콜옵션 가격 · PV(K): 행사가격의 현재가치 · P: 풋옵션 가격 · S: 현재 기초자산 가격
  • PV(K) = 100 ÷ (1 + 0.04 × 0.5) = 100 ÷ 1.02 ≈ 98.04
  • P = 6 + 98.04 − 100 ≈ 4.04
  • S = K여도 금리 때문에 콜이 풋보다 비싸다.
    K: 행사가격

암기

  • 풋-콜 패리티: 콜 + 채권(PV(K)) = 풋 + 주식
    PV(K): 행사가격의 현재가치
  • P = C + PV(K) − S
    P: 풋옵션 가격 · C: 콜옵션 가격 · S: 현재 기초자산 가격

계산기 꿀팁

P = C + K ÷ (1 + r·t) − S

P: 풋옵션 가격 · C: 콜옵션 가격 · K: 행사가격 · r: 무위험이자율(연) · t: 잔존만기(연 단위) · S: 현재 기초자산 가격

일반 계산기

  1. 0.04 × 0.5 + 1 = → 1.02 → M+
  2. 100 ÷ MR = → 98.04
  3. + 6 − 100 = → 4.04

공학용 계산기

6 + 100 ÷ ( 1 + 0.04 × 0.5 ) − 100 SHIFT = → 4.039

꿀팁 '콜 + 채권 = 풋 + 주식'(C + B = P + S)으로 외우면 어느 것을 구하든 이항만 하면 된다. S = K인 등가격이면 C − P = K − PV(K) = 행사가격의 이자(약 1.96)라서, 6 − 1.96 ≈ 4.04로 암산도 된다.

B: 채권(만기에 K를 주는 무위험채권) · PV(K): 행사가격의 현재가치

실무에서는

  • 패리티가 깨지면 컨버전/리버설로 무위험 차익을 얻을 수 있어 시장에서는 이 관계가 거의 유지된다.
  • 한쪽 옵션 가격만 알면 반대쪽 적정가와 합성 포지션(합성 선물 등) 가격을 바로 계산할 수 있다.

가상 사례패리티 이탈 차익거래

  • 행사가 100 콜이 6일 때 패리티상 풋은 약 4.04인데, A증권 옵션 데스크가 풋이 5에 거래되는 것을 발견했다.
  • 비싼 풋을 팔고 콜을 사면서 기초자산을 공매도해 대금을 예치하는 리버설로 약 1의 무위험 차익을 잡았다.

→ C + PV(X) = P + S가 깨지면 컨버전·리버설로 즉시 되돌아간다.

C: 콜옵션 가격 · P: 풋옵션 가격 · S: 현재 기초자산 가격
