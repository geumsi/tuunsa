정답 4번 위험전이방법 - Static CDO / Arbitrage CDO

개념

CDO(Collateralized Debt Obligation, 부채담보부증권)는 분류 기준 3가지에 따라 각각 2가지 유형으로 나뉜다. 기준과 유형을 짝으로 기억한다.

  • 발행목적: Arbitrage CDO(차익 목적), Balance sheet CDO(위험전가 목적)
  • 위험전이방법: Cash flow CDO(기초자산을 SPC(Special Purpose Company, 특수목적회사)에 양도), Synthetic(합성형(자산 양도 없이 CDS로 신용위험만 이전)) CDO(양도하지 않고 CDS(Credit Default Swap, 신용부도스왑) 등으로 신용위험만 이전)
  • 기초자산 운용방법: Static CDO(만기까지 포트폴리오를 바꾸지 않음), Dynamic CDO(지정된 운용자가 운용)
  • 기초자산 종류: 대출이면 CLO(Collateralized Loan Obligation, 대출채권담보부증권), 채권이면 CBO(Collateralized Bond Obligation, 채권담보부증권)

해설

위험전이방법에 따른 유형은 Cash flow CDO와 Synthetic CDO다. Static은 운용방법, Arbitrage는 발행목적 기준의 유형이다.

암기

  • 발행목적 → Arbitrage / Balance sheet
  • 위험전이방법 → Cash flow / Synthetic
    Synthetic: 합성형(자산 양도 없이 CDS로 신용위험만 이전)
  • 운용방법 → Static / Dynamic

실무에서는

  • CDO 분류는 왜 만들었는지, 위험을 어떻게 옮기는지, 담긴 자산을 운용하는지 세 질문에 각각 답한다.
  • Dynamic CDO는 운용자가 자산을 교체할 수 있어 운용자 역량을 함께 심사한다.
  • 분류 기준과 유형 이름이 다른 축에서 섞이면 틀린 연결이다.

보기별 해설

1발행목적 - Arbitrage CDO / Balance sheet CDO
CDO: 부채담보부증권
용어

발행목적에 따른 분류는 차익 추구(Arbitrage)와 위험전가·자본관리(Balance sheet)로 나뉜다.

이론

옳은 연결이라 정답이 아니다. Balance sheet CDO는 보유자산의 신용위험을 덜어내 재무구조를 개선하려고 발행한다.

실무

은행이 발행하면 Balance sheet, 운용사가 발행하면 Arbitrage인 경우가 많다.

2위험전이방법 - Cash flow CDO / Synthetic CDO
CDO: 부채담보부증권 · Synthetic: 합성형(자산 양도 없이 CDS로 신용위험만 이전)
용어

위험전이방법에 따른 분류는 자산을 실제로 양도하는지 여부로 구분한다.

이론

옳은 연결이라 정답이 아니다. Cash flow CDO는 기초자산을 SPC에 양도하고, Synthetic CDO는 CDS로 신용위험만 이전한다.

실무

차주 동의가 필요해 양도가 어려운 대출은 합성 방식으로 위험을 이전한다.

3기초자산 운용방법 - Static CDO / Dynamic CDO
CDO: 부채담보부증권
용어

기초자산 운용방법에 따른 분류는 포트폴리오를 만기까지 고정하는지, 운용자가 교체하는지로 구분한다.

이론

옳은 연결이라 정답이 아니다. Static은 만기까지 운용하지 않고, Dynamic은 지정된 운용자가 교체·운용한다.

실무

CLO는 대부분 운용자가 있는 Managed(Dynamic) 구조다.

4위험전이방법 - Static CDO / Arbitrage CDO정답
CDO: 부채담보부증권
용어

Static과 Arbitrage는 서로 다른 분류 기준에 속하는 유형이다.

이론

이 연결은 틀렸으므로 정답이다. 위험전이방법이 아닌 다른 두 기준의 유형을 섞었다.
