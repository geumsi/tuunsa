생명보험의 보험료 구성으로 옳은 것은?

  1. 순보험료 = 위험보험료 + 저축보험료, 부가보험료 = 신계약비 + 유지비 + 수금비
  2. 순보험료 = 위험보험료 + 부가보험료
  3. 부가보험료 = 위험보험료 + 저축보험료
  4. 순보험료 = 신계약비 + 유지비 + 수금비
정답과 해설 보기

정답 1번 순보험료 = 위험보험료 + 저축보험료, 부가보험료 = 신계약비 + 유지비 + 수금비

개념

생명보험의 보험료는 보험금 지급과 적립에 쓰는 순보험료와, 보험회사 운영에 쓰는 부가보험료로 나뉜다.

보험료 = 순보험료 + 부가보험료
순보험료 = 위험보험료 + 저축보험료
부가보험료 = 신계약비 + 유지비 + 수금비
  • 위험보험료 = 사망 등 보험사고에 보험금을 주기 위한 부분
  • 저축보험료 = 만기보험금이나 해지환급금을 위해 쌓는 부분
  • 신계약비 = 계약을 새로 맺는 데 드는 비용(모집수당 등)
  • 유지비 = 계약을 유지·관리하는 비용, 수금비 = 보험료를 걷는 비용

해설

보험료는 순보험료와 부가보험료로 나뉜다. 순보험료는 위험보험료+저축보험료, 부가보험료는 신계약비+유지비+수금비다.

암기

  • 보험료 = 순보험료 + 부가보험료
  • 순보험료 = 위험 + 저축
  • 부가보험료 = 신계약비 + 유지비 + 수금비

실무에서는

  • 보험료 구성을 알면 고객 돈 중 얼마가 보장·저축에 쓰이고 얼마가 사업비로 나가는지 설명할 수 있다.
  • 중도해지 환급금이 납입액보다 적은 것은 신계약비를 초기에 집중해 떼기 때문이며 민원의 핵심이다.
  • 저축성보험을 예금·투자와 비교할 때 사업비 차감을 빠뜨리면 불완전판매가 된다.

가상 사례저축성보험 조기 해지

  • 고객 D씨는 월 50만원씩 2년간 1,200만원을 낸 저축성보험을 해지했다.
  • 신계약비가 초기에 집중 차감돼 해지환급금은 약 900만원에 그쳤다.

→ 영업보험료는 순보험료와 부가보험료(사업비)로 구성되며, 사업비 차감을 빼고 예금과 비교하면 불완전판매가 된다.

보기별 해설

1순보험료 = 위험보험료 + 저축보험료, 부가보험료 = 신계약비 + 유지비 + 수금비정답
용어

영업보험료는 고객이 실제로 내는 보험료로 순보험료와 부가보험료를 합한 것이다.

이론

이 보기가 정답이다. 위험보험료는 보험금 지급 재원, 저축보험료는 만기·해지환급금 재원, 부가보험료는 보험회사 운영 경비다.

2순보험료 = 위험보험료 + 부가보험료
용어

부가보험료는 보험회사의 사업비 재원이다.

이론

틀린 보기다. 부가보험료는 순보험료에 들어가지 않고 순보험료와 대등한 구성 요소다.

실무

보험 상품 공시에서 사업비 비율은 부가보험료 기준으로 표시된다.

3부가보험료 = 위험보험료 + 저축보험료
용어

위험보험료와 저축보험료는 순보험료의 구성 요소다.

이론

틀린 보기다. 두 보험료는 부가보험료가 아니라 순보험료를 이룬다.

실무

보장성보험은 위험보험료 비중이, 저축성보험은 저축보험료 비중이 크다.

4순보험료 = 신계약비 + 유지비 + 수금비
용어

신계약비는 모집수수료 등 계약 체결 비용, 유지비는 계약 관리 비용, 수금비는 보험료 수금 비용이다.

이론

틀린 보기다. 세 비용은 순보험료가 아니라 부가보험료의 구성이다.

실무

설계사 모집수수료가 신계약비에서 나가므로 수수료 규제가 강화되면 신계약비 구조도 바뀐다.
